# CINE AI

**One idea → a short-film production package.**

CINE AI V2 is a GitHub Pages-ready short-film planning studio. It turns one film brief into a screenplay, character reference bible, scene breakdown and shot-by-shot video prompts.

## V2 features
- One-prompt short-film brief
- Ready-made Maharana Pratap historical short-film preset
- 1–3 minute film duration
- 3D animation, 2D cartoon, anime, realistic, stop motion and storybook styles
- Hindi, English or bilingual dialogue planning
- Optional local screenplay generation with Ollama (default model: `llama3.2`)
- Complete screenplay field with dialogue and narration
- Character bible with reusable appearance and voice descriptions
- Scene breakdown and 2–4 shot prompts per scene when generated by the local AI
- Editable scene and shot prompts
- Copy screenplay, scene prompts and shot prompts
- Export complete production package as JSON
- Browser-local project save

## Run / publish
No build tools or package installation are required.
- Local: open `index.html` in a modern browser.
- GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Optional local AI with Ollama
1. Start Ollama on your computer.
2. Download a model if needed: `ollama pull llama3.2`.
3. Keep the Ollama server running.
4. Open CINE AI, set the local server URL to `http://localhost:11434`, then use **Test local AI connection**.
5. If the browser blocks the connection, configure Ollama allowed origins to include the exact GitHub Pages origin and restart Ollama. Do not expose the Ollama port publicly.

The browser talks directly to Ollama at `http://localhost:11434`. This is optional; without it, a basic fallback storyboard is produced. The richer full screenplay and shot breakdown require a working local model.

## What V2 does and does not do
V2 creates the **screenplay and production package**. It does not yet synthesize animated video clips or export a finished MP4.

## Next milestone: actual video generation and film assembly
The next engineering milestone is a local generation bridge to a compatible ComfyUI/video-model workflow, followed by clip management, voice/music/SFX and MP4 assembly. GitHub Pages is static hosting and cannot run a large video model. Online video providers must be connected through a secure server-side proxy; never place private API keys in public frontend code. Free model availability, hardware requirements, queue limits and usage rights vary.

## Hardware note
Local video generation can be demanding. A laptop with 8 GB RAM and integrated graphics is suitable for running the studio and lightweight text planning, but many modern video models need significantly more memory and GPU capability. We will keep the interface compatible with a remote/local generation bridge rather than assuming this machine can render every model.

## Privacy
Projects are saved in this browser's local storage. Export JSON for backup. Do not enter confidential material into a public or shared computer.
