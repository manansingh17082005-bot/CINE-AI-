# CINE AI

**One idea → a short-film production package.**

CINE AI V2 is a GitHub Pages-ready short-film planning studio. It turns one film brief into a screenplay, character reference bible, scene breakdown and shot-by-shot video prompts.

## V2 features
- One-prompt short-film brief
- Ready-made Maharana Pratap historical short-film preset
- 1–3 minute film duration
- 3D animation, 2D cartoon, anime, realistic, stop motion and storybook styles
- Hindi, English or bilingual dialogue planning
- Optional local screenplay generation with Ollama (default model: `llama3.2`)
- Complete screenplay field with dialogue and narration
- Character bible with reusable appearance and voice descriptions
- Scene breakdown and 2–4 shot prompts per scene when generated by the local AI
- Editable scene and shot prompts
- Copy screenplay, scene prompts and shot prompts
- Export complete production package as JSON
- Browser-local project save

## Run / publish
No build tools or package installation are required.
- Local: open `index.html` in a modern browser.
- GitHub Pages: Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.

## Optional local AI with Ollama
1. Start Ollama on your computer.
2. Download a model if needed: `ollama pull llama3.2`.
3. Keep the Ollama server running.
4. Open CINE AI, set the local server URL to `http://localhost:11434`, then use **Test local AI connection**.
5. If the browser blocks the connection, configure Ollama allowed origins to include the exact GitHub Pages origin and restart Ollama. Do not expose the Ollama port publicly.

The browser talks directly to Ollama at `http://localhost:11434`. This is optional; without it, a basic fallback storyboard is produced. The richer full screenplay and shot breakdown require a working local model.

## What V2 does and does not do
V2 creates the **screenplay and production package**. It does not yet synthesize animated video clips or export a finished MP4.

## Next milestone: actual video generation and film assembly
The next engineering milestone is a local generation bridge to a compatible ComfyUI/video-model workflow, followed by clip management, voice/music/SFX and MP4 assembly. GitHub Pages is static hosting and cannot run a large video model. Online video providers must be connected through a secure server-side proxy; never place private API keys in public frontend code. Free model availability, hardware requirements, queue limits and usage rights vary.

## Hardware note
Local video generation can be demanding. A laptop with 8 GB RAM and integrated graphics is suitable for running the studio and lightweight text planning, but many modern video models need significantly more memory and GPU capability. We will keep the interface compatible with a remote/local generation bridge rather than assuming this machine can render every model.

## Privacy
Projects are saved in this browser's local storage. Export JSON for backup. Do not enter confidential material into a public or shared computer.


## V3: free-tier AI video generation

V3 adds a real text-to-video clip workflow through Magic Hour's API, routed through a Supabase Edge Function. The browser never receives the Magic Hour API key.

### Free-only safety rules
- The server checks the Magic Hour account before each request and refuses generation unless the account tier is `free` and there is no active subscription.
- The server always fixes the model to `ltx-2.5`, resolution to `480p`, duration to `5 seconds`, and audio off. The browser cannot override those settings.
- If the account has no credits, the function returns an error and does not switch to a paid model.
- Do not add a payment method, activate a subscription, buy credit packs, or enable usage-based billing if you want to keep this at zero cost. Free signup credits are limited and provider terms can change.
- This is clip generation, not a finished long-form MP4 editor. Each scene currently produces one 5-second clip. Full film assembly, audio mix and subtitles are later milestones.

Magic Hour's official docs describe free signup credits, the free-tier default model (LTX-2.5), and the account endpoint that exposes tier and available credits:
- https://magichour.ai/api/text-to-video
- https://docs.magichour.ai/tools/video/text-to-video
- https://docs.magichour.ai/api-reference/account/get-account-details

### One-time setup

1. Create a free Magic Hour developer account at https://magichour.ai/developer. Do not add a card or start a paid plan. Create an API key and keep it private.
2. Create or use a Supabase project. On Windows, if Node.js 20+ is installed, open PowerShell in this repository and install the CLI locally with `npm install supabase --save-dev`. Use `npx supabase` for the commands below. Alternatively, install the CLI with Scoop using the official Supabase CLI instructions.
3. Sign in and link your Supabase project:
   ```powershell
   npx supabase login
   npx supabase link --project-ref YOUR_SUPABASE_PROJECT_REF
   ```
4. Generate a long random private access token using a password manager. Set the two secrets in your terminal environment (replace the values locally; never commit them):
   ```powershell
   $env:MAGIC_HOUR_API_KEY="paste-your-Magic-Hour-key-here"
   $env:CINE_ACCESS_TOKEN="paste-a-long-random-private-token-here"
   npx supabase secrets set MAGIC_HOUR_API_KEY=$env:MAGIC_HOUR_API_KEY CINE_ACCESS_TOKEN=$env:CINE_ACCESS_TOKEN
   ```
5. Deploy the function:
   ```powershell
   npx supabase functions deploy cine-video --no-verify-jwt
   ```
6. Copy the function URL. It looks like:
   `https://YOUR_PROJECT_REF.supabase.co/functions/v1/cine-video`
7. Open the GitHub Pages site, enter the function URL and the same private CINE access token in the Video Engine section, choose **Save video connection**, then **Test connection**.
8. Generate a screenplay, then click **Generate 5-sec AI clip** on a scene.

### Security notes
- `MAGIC_HOUR_API_KEY` and `CINE_ACCESS_TOKEN` belong only in Supabase Function secrets. Never paste them into `index.html`, GitHub, screenshots, or chat.
- The private CINE access token is stored in the current browser tab's session storage, not committed to the repository. Anyone who knows that token can use the proxy, so keep it private and rotate it if exposed.
- The function accepts requests only from this GitHub Pages origin and checks the private token server-side.
- The free-tier check prevents use when the account has a paid subscription. It cannot distinguish free signup credits from credit packs purchased on a free-tier account; do not purchase credits if you require zero spend.
